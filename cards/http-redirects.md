# Чем отличаются редиректы 301, 302 и 307?

## Ответ

Все коды `3xx` говорят браузеру: «иди по другому адресу», но по-разному влияют на кеширование и метод запроса.

```
301 Moved Permanently — ресурс переехал навсегда.
                         Браузер и поисковики кешируют редирект надолго.
                         Метод запроса может измениться (POST → GET).

302 Found              — ресурс временно доступен по другому URL.
                         Не кешируется агрессивно.
                         Метод тоже иногда меняется на GET (не по стандарту, но так исторически делают браузеры).

307 Temporary Redirect — как 302, но строго сохраняет метод и тело запроса.
                         POST останется POST.

308 Permanent Redirect — как 301, но тоже строго сохраняет метод.
```

Практическое правило:
- Переезд страницы навсегда (SEO) → `301` или `308`
- Временный редирект с сохранением метода (например, после отправки формы) → `307`
- `302` — самый "размытый" по поведению, для новых API лучше явно использовать `307`/`308`.
