# Когда использовать Present Perfect вместо Past Simple в рабочей речи?

## Ответ

Частая ошибка русскоговорящих разработчиков — путать эти времена, потому что в русском нет прямого аналога.

**Past Simple** — законченное действие в **конкретный момент прошлого** (важно "когда"):

```
I fixed the bug yesterday.
I deployed the update at 3 PM.
```

**Present Perfect** — действие, **результат которого важен сейчас**, момент не уточняется:

```
I have fixed the bug. (важно, что уже исправлено — сейчас)
I have already deployed the update.
Have you reviewed my PR yet?
```

Практика для стендапов:

| Ситуация | Пример |
|---|---|
| Отчёт "что сделал вчера" (важна дата) | "Yesterday I **wrote** the tests." |
| Статус сейчас (результат важнее даты) | "I **have written** the tests, they're passing." |
| Ещё не сделано | "I **haven't finished** the migration yet." |
| Опыт без указания даты | "I **have worked** with Kubernetes before." |

Ключевые слова-подсказки:
- Past Simple: `yesterday`, `last week`, `in 2023`, `at 5 PM`
- Present Perfect: `already`, `yet`, `just`, `ever`, `never`, `since`, `for`
