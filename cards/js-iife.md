# Что такое IIFE (Immediately Invoked Function Expression) и зачем оно нужно?

## Ответ

IIFE — функция, которая **вызывается сразу же после объявления**, обёрнутая в скобки:

```js
(function () {
  console.log('запустилась сразу');
})();

// Стрелочная версия
(() => {
  console.log('тоже сразу');
})();
```

Главная цель — создать **изолированную область видимости**, чтобы переменные внутри не утекали в глобальный скоуп:

```js
(function () {
  var secret = 42; // недоступна снаружи
})();

console.log(typeof secret); // "undefined"
```

До появления `let`/`const` и ES-модулей IIFE был основным способом избежать конфликтов имён между скриптами на странице. Сегодня используется реже — модули (`import`/`export`) и блочная область видимости (`let`, `const`) решают ту же задачу, но паттерн всё ещё встречается в легаси-коде и в некоторых библиотеках (например, для немедленного `async`-запуска):

```js
(async () => {
  const data = await fetch('/api/users').then((r) => r.json());
  console.log(data);
})();
```
