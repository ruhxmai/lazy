# Что такое ACID в базах данных?

## Ответ

Четыре свойства, гарантирующие надёжность транзакций:

- **Atomicity (атомарность)** — транзакция выполняется целиком или не выполняется вовсе
- **Consistency (согласованность)** — данные переходят из одного валидного состояния в другое
- **Isolation (изолированность)** — параллельные транзакции не мешают друг другу
- **Durability (устойчивость)** — после `COMMIT` данные сохранятся даже при сбое

```sql
BEGIN;
UPDATE accounts SET balance = balance - 100 WHERE id = 1;
UPDATE accounts SET balance = balance + 100 WHERE id = 2;
COMMIT;
```

Если сервер упадёт между двумя `UPDATE`, Atomicity гарантирует: либо оба выполнятся при следующем коммите, либо откатятся оба (`ROLLBACK`) — деньги не «потеряются» и не «удвоятся».
