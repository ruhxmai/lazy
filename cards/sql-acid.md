# Что такое ACID и почему это важно для транзакций?

## Ответ

**ACID** — 4 свойства, которые гарантируют надёжность транзакций в реляционных БД:

- **Atomicity (атомарность)** — транзакция выполняется целиком или не выполняется вовсе
- **Consistency (согласованность)** — БД переходит из одного валидного состояния в другое
- **Isolation (изолированность)** — параллельные транзакции не мешают друг другу
- **Durability (устойчивость)** — после `COMMIT` изменения сохраняются даже при сбое

```sql
BEGIN;
UPDATE accounts SET balance = balance - 100 WHERE id = 1;
UPDATE accounts SET balance = balance + 100 WHERE id = 2;
COMMIT; -- либо обе строки обновятся, либо ни одной (Atomicity)
```

Если между `UPDATE`-ами произойдёт сбой — `ROLLBACK` отменит все изменения транзакции, деньги не «потеряются» и не «удвоятся».
