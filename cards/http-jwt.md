# Что такое JWT и из каких частей он состоит?

## Ответ

**JWT (JSON Web Token)** — компактный токен для передачи данных о пользователе между клиентом и сервером. Состоит из трёх частей, разделённых точками:

```
header.payload.signature
```

```js
// Пример декодированного токена
{
  // header — алгоритм подписи
  "alg": "HS256",
  "typ": "JWT"
}
{
  // payload — данные (не шифруются, только кодируются!)
  "userId": 42,
  "role": "admin",
  "exp": 1735689600
}
// signature — HMAC(header + payload, секретный ключ сервера)
```

Токен передаётся в заголовке запроса:

```http
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

**Важно:** payload лишь закодирован в Base64, а не зашифрован — любой может его прочитать. Подделать токен нельзя без секретного ключа, но **хранить пароли или другие секреты в payload нельзя**.

Сервер не хранит сессии — он **stateless**: просто проверяет подпись при каждом запросе.
