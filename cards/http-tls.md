# Как работает HTTPS и зачем нужен TLS?

## Ответ

HTTPS = HTTP + шифрование через **TLS** (Transport Layer Security). Защищает от перехвата и подмены данных между клиентом и сервером.

Упрощённо, при подключении происходит **TLS handshake**:

1. Клиент говорит серверу, какие шифры поддерживает
2. Сервер присылает сертификат (публичный ключ, подписанный доверенным CA)
3. Клиент проверяет сертификат и договаривается о сессионном ключе
4. Дальше весь трафик шифруется симметричным ключом (это быстрее, чем асимметричным)

```
Клиент --ClientHello-->        Сервер
Клиент <--Certificate---       Сервер
Клиент --проверка CA, обмен ключом-->
Клиент <===зашифрованные данные===>  Сервер
```

Без HTTPS пароли, cookies и токены передаются открытым текстом — их может прочитать любой на пути пакета (Wi-Fi, прокси, провайдер).
