# Почему `[10, 1, 2].sort()` даёт `[1, 10, 2]`, а не `[1, 2, 10]`?

## Ответ

По умолчанию `sort()` без компаратора превращает элементы в **строки** и сравнивает их лексикографически (посимвольно), а не как числа.

```js
const nums = [10, 1, 2];

nums.sort();
// [1, 10, 2] — потому что "10" < "2" по строковому сравнению

nums.sort((a, b) => a - b);
// [1, 2, 10] — правильная числовая сортировка
```

- `a - b` — по возрастанию, `b - a` — по убыванию.
- `sort()` мутирует исходный массив (изменяет его на месте), а не создаёт новый — если нужен новый массив, используйте `[...nums].sort(...)` или `nums.toSorted(...)` (ES2023).
- Для строк с кириллицей или спецсимволами используйте `localeCompare()` вместо простого сравнения `<`/`>`.
