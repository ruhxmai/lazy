# В чём разница между селекторами `.a .b`, `.a > .b`, `.a + .b` и `.a ~ .b`?

## Ответ

Это **комбинаторы** — определяют связь между элементами в селекторе.

```css
.a .b   { } /* потомок: .b где угодно внутри .a */
.a > .b { } /* прямой потомок: .b — непосредственный ребёнок .a */
.a + .b { } /* соседний элемент: .b сразу после .a на том же уровне */
.a ~ .b { } /* все последующие соседи: любой .b после .a на том же уровне */
```

```html
<div class="a">
  <span class="b">1 — совпадёт с .a .b и .a > .b</span>
  <p><span class="b">2 — совпадёт только с .a .b</span></p>
</div>
<p class="b">3 — совпадёт с .a + .b и .a ~ .b</p>
<p class="b">4 — совпадёт только с .a ~ .b</p>
```

**Запомнить:**
- Пробел — потомок (любой уровень вложенности)
- `>` — только прямой ребёнок
- `+` — следующий соседний элемент (один)
- `~` — все следующие соседние элементы
