# Чем WebSocket отличается от обычных HTTP-запросов?

## Ответ

WebSocket — это протокол, который открывает **постоянное двустороннее соединение** между клиентом и сервером поверх одного TCP-соединения, в отличие от HTTP, где каждый запрос требует нового цикла запрос-ответ.

```js
const socket = new WebSocket("wss://example.com/chat");

socket.onopen = () => socket.send("привет");
socket.onmessage = (event) => console.log(event.data);
socket.onclose = () => console.log("соединение закрыто");
```

Ключевые отличия:

| HTTP | WebSocket |
|---|---|
| Запрос → ответ, соединение закрывается | Соединение остаётся открытым |
| Клиент всегда инициатор | Сервер может сам отправлять данные |
| Больше накладных расходов на каждый запрос | Один handshake, дальше — лёгкие фреймы |

Соединение начинается как обычный HTTP-запрос с заголовком `Upgrade: websocket`, после чего протокол "переключается" (`101 Switching Protocols`).

Используется для чатов, live-уведомлений, онлайн-игр, совместного редактирования.
