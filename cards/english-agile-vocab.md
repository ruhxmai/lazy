# Как называются ключевые термины Agile/Scrum на английском?

## Ответ

- **Sprint** — короткий цикл работы (обычно 1–2 недели)
- **Backlog** — список задач на выполнение
- **Story points** — оценка сложности задачи
- **Stand-up** — короткая ежедневная встреча
- **Retrospective (retro)** — обсуждение прошедшего спринта
- **Blocker** — то, что мешает продвигаться по задаче
- **Definition of Done (DoD)** — критерии завершённости задачи
- **Velocity** — скорость команды (сколько story points закрывается за спринт)

Пример фразы на стендапе:

```text
"This ticket is blocked, waiting on backend.
Should be unblocked by tomorrow's standup."
```
