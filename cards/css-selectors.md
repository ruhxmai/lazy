# Какие бывают CSS-селекторы и комбинаторы?

## Ответ

**Базовые селекторы:**

```css
.class      { }  /* по классу */
#id         { }  /* по id */
element     { }  /* по тегу */
[attr]      { }  /* по атрибуту */
[attr=val]  { }  /* по значению атрибута */
*           { }  /* универсальный */
```

**Комбинаторы** — определяют связь между элементами:

```css
.parent .child     { }  /* потомок на любом уровне вложенности */
.parent > .child   { }  /* прямой потомок (один уровень) */
.item + .item      { }  /* соседний элемент сразу после */
.item ~ .item      { }  /* все последующие соседи */
```

```html
<div class="parent">
  <span class="child">найдёт .parent .child и .parent > .child</span>
  <p class="item">1</p>
  <p class="item">2 — найдёт .item + .item и .item ~ .item</p>
  <p class="item">3 — найдёт только .item ~ .item</p>
</div>
```

**Группировка и объединение условий:**

```css
h1, h2, h3 { }           /* группа: любой из тегов */
input.error { }          /* пересечение: input И класс error */
a:not(.disabled) { }     /* исключение */
```

Чем длиннее и специфичнее селектор — тем выше его вес в каскаде (см. специфичность), поэтому не стоит злоупотреблять глубокой вложенностью.
