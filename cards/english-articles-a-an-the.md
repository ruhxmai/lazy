# Когда использовать a, an и the в технической речи?

## Ответ

Артикли — частая проблема для русскоговорящих разработчиков, в русском их нет.

```
a / an — неопределённый артикль, "какой-то один из..."
  a bug, a function, an array, an error

the — определённый артикль, "тот самый, конкретный"
  the bug we fixed yesterday, the main branch

Без артикля — для неисчисляемых и общих понятий
  I love JavaScript. We use Git for version control.
```

**Правило a/an:** зависит от звука следующего слова, не от буквы.
- `a user` (звук «ю»), `an hour` (звук «ауэ», «h» не читается)
- `a UI component`, `an API` (звук «эй»)

Частая ошибка: *"I found bug in code"* → правильно: *"I found **a** bug in **the** code"*.
