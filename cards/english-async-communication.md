# Как вежливо писать в Slack/таск-трекере, если ты не успеваешь?

## Ответ

**Сообщить о задержке заранее:**
- *"I'm running a bit behind on this — it'll take another day."*
- *"This turned out more complex than expected, so I'm pushing the ETA to Friday."*
- *"I might need an extra day to finish this properly."*

**Попросить помощи, не звучав беспомощно:**
- *"Could someone double-check my approach here before I go further?"*
- *"I'm stuck on X — has anyone dealt with this before?"*

**Асинхронный статус-апдейт:**
- *"Quick update: finished the API integration, starting on tests now."*
- *"Blocked on the design review — will pick this up once I get feedback."*

**Полезные фразы:**
- *"No rush, whenever you get a chance"* — не срочно, когда будет время
- *"Just following up on..."* — просто напоминаю про...
- *"Thanks for your patience"* — спасибо за терпение
