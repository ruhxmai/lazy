# В чём разница между HTTP-методами PUT и PATCH?

## Ответ

Оба метода обновляют существующий ресурс, но по-разному:

- **`PUT`** — заменяет ресурс **целиком**. Нужно передать все поля объекта
- **`PATCH`** — обновляет **частично**, только переданные поля

```http
# PUT — полная замена: если не передать email, он может обнулиться
PUT /users/42
{ "name": "Anna", "email": "anna@mail.com", "age": 25 }

# PATCH — частичное обновление: остальные поля не трогаем
PATCH /users/42
{ "age": 26 }
```

Оба метода **идемпотентны** — повторный одинаковый запрос даёт тот же результат. А вот `POST` — не идемпотентен, повторный вызов может создать дубликат.
